NEON OVERLOAD — installable clicker game

1. Extract this ZIP into a folder.
2. To install as a proper app, the files need to be hosted on HTTPS (for example, GitHub Pages or Netlify).
3. Open the hosted site in Chrome or Edge on Windows.
4. Click the install icon in the address bar, or use browser menu > Save and share > Install page as app.
5. Your progress saves automatically in that browser on that device.

Important:
- The game works offline after its first successful load when hosted as an installable PWA.
- Save data is stored locally in the browser. Clearing browser site data can erase it.
- Use the in-game Export save button to make a backup JSON file.
- The exported save is a backup; automatic syncing between devices is not included.
